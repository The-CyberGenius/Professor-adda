# Professor Adda - Premium NET JRF Notes Website 📚

A modern, responsive website for Professor Adda offering premium NET JRF preparation notes in both PDF and hard copy formats.

## Features

- 🎨 Modern, responsive design with gradient themes
- 📱 Mobile-friendly navigation
- 📄 Sample PDF preview and download
- 💬 WhatsApp integration for easy contact
- ⚡ Fast loading with optimized assets
- 🎯 SEO-friendly structure

## Tech Stack

- HTML5
- CSS3 (Custom styles + Tailwind CSS)
- Vanilla JavaScript
- Web Components (Custom Elements API)

## Project Structure

```
professor adda website/
├── components/
│   ├── navbar.js      # Navigation bar component
│   └── footer.js      # Footer component
├── index.html         # Main HTML file
├── style.css          # Custom styles
├── script.js          # Main JavaScript
└── sample-notes.pdf   # Sample notes file
```

## Setup & Deployment
Professoradda.com hosted on Hostinger Basic plan  

### Local Development

1. Clone the repository
2. Open `index.html` in a browser or use a local server:
   ```bash
   python -m http.server 8000
   # or
   npx serve
   ```

### Deploy to Vercel/Netlify

1. Push code to GitHub
2. Connect repository to Vercel/Netlify
3. Deploy automatically
